# Campus Connect – Student Portal

Campus Connect is a student portal designed to help students access university updates, events, study resources, and other useful information in one place.

## Features

* **Login & Signup:** Student account interface.
* **Dashboard:** Quick overview of portal updates.
* **Announcements:** View important university notices.
* **Events:** Explore upcoming events and registration options.
* **Lost & Found:** Post and view lost or found items.
* **Study Resources:** Access useful learning materials.
* **Student Profile:** View student profile information.
* **Help & Support:** Find support information.
* **Theme Options:** Switch between different color themes.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

* `index.html` – Main dashboard
* `login.html` – Login page
* `signup.html` – Signup page
* `css/style.css` – Styling and layout
* `js/script.js` – Dashboard interactions
* `js/auth.js` – Login and signup functionality

## Getting Started

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `login.html` in your browser to start.

## Project Status

This project is a frontend prototype. Backend integration and database functionality can be added in the future.
